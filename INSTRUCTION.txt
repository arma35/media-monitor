# Media Monitor 4.1.1 — инструкция для пользователя

Программа ищет заданные слова/фразы на указанных сайтах СМИ и пишет результат в Excel-отчёт.

**v4** — окно (Старт / Пауза / Стоп / лог) + SQLite-кэш уже просмотренных страниц.
Консоль: `media-monitor-v4.1.1.exe --console`.
Линия **v3.x** — без кэша URL.

Сайты сканируются параллельно; внутри сайта — по очереди.
Excel пишет один раз в конце (и открывается автоматически).

Запуск: распакуйте zip в папку, затем `media-monitor-v4.1.1.exe` (рядом должна быть папка `_internal` — не удаляйте её).

**Важно:** не запускайте exe прямо из архива — сначала распакуйте. Сборка onedir стартует за секунды (раньше onefile мог «виснуть» 1–2 минуты при каждом запуске).

## Что лежит в папке

| Файл | Назначение |
|---|---|
| `media-monitor-v4.1.1.exe` | Запуск (окно) |
| `_internal\` | Служебные библиотеки (не удалять) |
| `sites.txt` | Список сайтов |
| `words.txt` | Слова и фразы |
| `settings.txt` | Настройки (даты, лимиты, кэш) |
| `exclude.txt` | URL, которые не нужны в отчёте |
| `scan_cache.sqlite` | Кэш уже проверенных страниц (создаётся сам) |
| `*.example.txt` | Образцы (ваши рабочие txt не затираются) |
| `reports\` | Excel-отчёты |
| `media-monitor_log.txt` | Полный лог работы |
| `ИНСТРУКЦИЯ.docx` / `.txt` | Эта инструкция |
| `INSTRUCTION.docx` / `.txt` | То же латиницей (если кириллица в имени файла отобразилась криво) |

Папку можно копировать на флешку целиком.

## Поиск в words.txt

| Как писать | Что ищется |
|---|---|
| `тройка карта принимается` | Все слова в статье, в любом порядке |
| `"карта Виза принимается в городе"` | Точная фраза подряд |

## Настройки (settings.txt)

При обновлении с v3 программа **сама допишет** новые ключи в ваш `settings.txt` (старые значения не трогает).

| Параметр | Смысл |
|---|---|
| `article_date_not_later_than` | Дата ДО (пусто = сегодня) |
| `article_date_not_older_than` | Дата НЕ СТАРШЕ (пусто = без нижней границы) |
| `article_date_last_days` | Последние N дней от сегодня; если >0 — перекрывает оба параметра дат |
| `auth_timeout_seconds` | Секунды на ввод логина/пароля |
| `max_scan_urls` | Лимит страниц **на один сайт** (`0` = без лимита) |
| `max_expand_links` | Сколько ссылок брать с одной страницы списка/поиска (**не** фильтр по дате) |
| `skip_seen_days` | Не качать повторно URL из кэша за N дней (`0` = выкл.) |
| `site_workers` | Сколько сайтов одновременно (`0` = все) |
| `log_verbose` | `0` — краткий статус; `1` — URL/ошибки |
| `comment_unavailable_sites` | `1` — закомментировать недоступный сайт в `sites.txt` |
| `ssl_verify` | `1` — проверять сертификаты |

Если дата статьи найдена и вне периода — в отчёт не попадёт.  
Если дата **не** найдена — статья всё равно может попасть (ячейка даты пустая).

## Кэш страниц (новое в 4.0)

Рядом с exe появляется `scan_cache.sqlite` — какие URL уже проверяли, когда и с каким набором слов.

- При `skip_seen_days=30` повторный прогон **не качает** эти URL (в логе: `[cache] уже смотрели`).
- В итоге сайта: `кэш-пропуск N`; в общем итоге: `кэш-пропуск N`.
- Сменили `words.txt` — кэш для старых фраз не действует, страницы снова сканируются.
- Сброс: удалите `scan_cache.sqlite` **или** поставьте `skip_seen_days=0`.
- **Совет:** первый прогон с большим `max_expand_links` (например `1000`), когда кэш наполнен — можно `100`–`120`.

## Что видно в окне

- **параллельно** — сколько сайтов качается сразу (`site_workers`).
- **Статьи: с … по …** — итоговый период из параметров дат.
- Полоса и строка прогресса + таймер с момента Старта.
- Вкладка **Статус** — краткий итог по сайтам (`готово` / `недоступен` / `остановлен`).
- Вкладка **Полный лог** — поиск, каждый URL, HIT, `[cache]`.

## Отчёт Excel

Файлы: `reports\media-monitor-ГГГГ-ММ-ДД_ЧЧ-ММ-СС.xlsx`

Сначала найденные статьи, в конце красным — недоступные и все закомментированные в `sites.txt` (`#`).

| Ячейка | Содержание |
|---|---|
| A | слово / фраза |
| B | ссылка (кликабельная) |
| C | дата выхода статьи |
| D | название |
| E | дата/время скана |
| F1 | версия (`v4.1.1`) |
| G1 | длительность |

Полный ход работы — в `media-monitor_log.txt`.

---

## Типичные сообщения

- `[N/M] готово сайт — … стр., кэш-пропуск N, … находок` — сайт закончен.
- `[N/M] недоступен сайт` — сайт недоступен (в Excel красным; строка в sites.txt с `#`).
- `[N/M] остановлен сайт` — прерван кнопкой Стоп.
- `[cache] уже смотрели: URL` — страница пропущена по кэшу (без HTTP).
- `Кэш: scan_cache.sqlite — в БД сейчас N ссылок…` — кэш включён при старте.
- `Кэш БД: было N, пропуск …, добавлено новых …, стало …` — итог по SQLite в конце.
- `Итог: …, кэш-пропуск N` — сколько URL не качали повторно.

## Пауза и Стоп

**Пауза** — временно не брать новые страницы (текущие HTTP докачиваются). Кнопка меняется на «Продолжить».
**Стоп** — сразу закрывает сетевые соединения; новые страницы не берутся.
Excel **всё равно сохраняется** с тем, что успели найти.

В верхней панели во время скана:
- «страниц проверено N» — сколько URL обработано (скан + кэш-пропуск);
- «БД кэш: было / проверено ранее / добавлено сейчас».

---

## Советы

- В `sites.txt` — главная или раздел новостей.
- После обновления exe ваши txt-конфиги не затираются; новые ключи settings допишутся сами.
- Если сайт режет по частоте — `site_workers=8`.
- Образец настроек — `settings.example.txt`.
- Если окно «тупит» на огромном списке сайтов — смотрите вкладку «Статус»; после окончания скана окно почти не грузит CPU.
- Запускайте exe с локального диска (не из папки Яндекс.Диска) — иначе синк лога тормозит систему.
