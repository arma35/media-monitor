# Media Monitor 1.0.0 — инструкция для пользователя

Программа ищет заданные слова/фразы на указанных сайтах СМИ и пишет результат в Excel-отчёт.

---

## Что лежит в папке

| Файл / папка | Назначение |
|---|---|
| `media-monitor.exe` | Запуск программы |
| `sites.txt` | Список сайтов для проверки |
| `words.txt` | Список слов и фраз для поиска |
| `settings.txt` | Настройки (даты, лимиты) |
| `exclude.txt` | Ссылки, которые **не** должны попадать в отчёт |
| `settings.example.txt` и др. `*.example.txt` | Образцы (можно смотреть, не обязательно править) |
| `reports\` | Сюда сохраняются Excel-отчёты |
| `media-monitor_log.txt` | Лог работы (то же, что в консоли) |

Программу можно копировать на флешку целиком — пути абсолютные не нужны.

---

## Быстрый старт

1. Откройте `sites.txt` — по одной ссылке на сайт в строке.  
   Пример:
   ```text
   gubdaily.ru
   amurmedia.ru
   dostup1.ru
   ```
2. Откройте `words.txt` — по одному слову или фразе в строке.  
   Пример:
   ```text
   сбертройка
   карта тройка
   ```
3. При необходимости настройте `settings.txt` (см. ниже).
4. Запустите `media-monitor.exe`.
5. Если спросят логин/пароль — можно просто нажать Enter (пропуск), либо ввести данные за отведённое время.
6. Дождитесь окончания. В конце будет «Нажмите Enter…».
7. Откройте свежий файл в папке `reports\`.

---

## Как работает поиск

- Регистр **не важен**: `СберТройка` = `сбертройка`.
- Строка в `words.txt` ищется **целиком** как фраза (можно несколько слов).
- Кавычки вокруг слова в статье не мешают: `"тройка"` тоже найдётся.
- Поиск идёт по тексту статьи, а не по меню/футеру сайта.
- Со страниц списков и через поиск сайта программа находит ссылки на статьи и проверяет их.

## Настройки (`settings.txt`)

Над каждым параметром в файле есть русский комментарий. Кратко:

| Параметр | Смысл |
|---|---|
| `article_date_not_later_than` | Дата **ДО** (включительно). Пусто = сегодня. |
| `article_date_not_older_than` | Дата **НЕ СТАРШЕ**. Пример `2026-01-01` — только с этой даты и новее. Пусто = без нижней границы. |
| `auth_timeout_seconds` | Сколько секунд ждать логин/пароль при старте. |
| `max_scan_urls` | Лимит страниц за запуск. `0` = без лимита. |
| `max_expand_links` | Сколько ссылок брать с одной страницы списка/поиска. |

**Важно про даты:**
- Если дата статьи **найдена** и она вне диапазона — статья в отчёт не попадёт.
- Если дата статьи **не найдена** — статья **всё равно** попадёт в отчёт (дата в Excel будет пустой).

Пример: статьи с 1 января 2026 по сегодня:
```text
article_date_not_later_than=
article_date_not_older_than=2026-01-01
```

---

## Исключения (`exclude.txt`)

Если какая-то статья находится, но в отчёт её не нужно — добавьте её URL (по одной в строке):

```text
https://gubdaily.ru/news/v-trollejbusax-petrozavodska-zarabotala-karta-trojka/
```

## Отчёт Excel

Файлы: `reports\media-monitor-ГГГГ-ММ-ДД_ЧЧ-ММ-СС.xlsx`

| Колонка | Содержание |
|---|---|
| A | слово / фраза |
| B | ссылка на страницу (кликабельная) |
| C | дата выхода статьи |
| D | название статьи |
| E | дата/время скана |
| **F1** | версия программы, например `v1.0.0` |
| **G1** | время генерации отчёта |

---

## Лог

- Файл: `media-monitor_log.txt` (рядом с exe).
- Пишется то же, что видно в консоли.
- Если лог вырастает больше **10 МБ**, старая часть обрезается автоматически.

---

## Типичные сообщения

| Сообщение | Что значит |
|---|---|
| `[ssl] … Повтор без проверки SSL` | У сайта кривой сертификат. В браузере может открываться, программа всё равно скачает страницу. |
| `[skip auth]` | Нужна авторизация, данных нет или они не подошли — страница пропущена. |
| `[warn] cannot expand …` | Не удалось раскрыть список ссылок с этой страницы. |
| `[error] …` | Ошибка загрузки конкретной страницы. |

---

## Советы

1. В `sites.txt` лучше указывать главную сайта или раздел новостей (`https://site.ru` или `https://site.ru/news/`).
2. Для точного поиска используйте фразу целиком в `words.txt`.
3. После обновления exe ваши `sites.txt` / `words.txt` / `settings.txt` / `exclude.txt` **не затираются**.
4. Образец настроек смотрите в `settings.example.txt` — при обновлении программы он может меняться.
